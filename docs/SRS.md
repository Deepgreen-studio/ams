# Software Requirements Specification (SRS)

## Product

Enterprise Application Management System (AMS)

## Goals

Manage Android, iOS, and Web applications from a centralized enterprise dashboard with strong authz, auditability, and modular domain growth.

## Current Implemented Scope

- Project foundation
- Monorepo architecture
- Authentication (login/logout/me/password reset)

## Upcoming Modules

Users, Roles, Companies, Dashboard, Applications, Customers, Integrations, Releases, Content, Support, Compliance, Notifications, Analytics, Reports, Settings
